# AndyChoir
Универсальный конструктор для AI агентов и оркестраторов.

# Архитектура
Центральным бинарником является приложение-хост. Оно загружает плагин конфигурации 
(по параметрам из командной строки или окружения) и на его основе подгружает и конфигурирует 
все нужные плагины. Кроме того, хост отвечает за шину сообщений между плагинами.

# Формат плагинов
Плагины загружаются как wasm приложения. Они должны экспортировать функцию `init` с сигнатурой 
`init(config: string): void`. Функция `init` должна принимать конфигурацию в виде строки JSON 
и инициализировать плагин.

# Базовые плагины
- Плагин загрузки **конфигурации** из JSON файла;
- Плагин **LLM**;
- Плагин **агента**;
- Плагин **оркестратора**;
- Плагины базовых **инструментов** (tools):
  - Инструменты работы с файловой системой (только чтение);
  - Инструменты работы с файловой системой (запись);
  - Инструменты для работы с поиском по интернету;
  - Инструмент-калькулятор;
  - Инструмент информации об окружении (текущее время, параметры окружения, информация о системе);
  - Инструмент для поиска по БД знаний. БД знаний могут быть несколько и идентифицируются они по именам;
  - Плагин для добавления новых данных в базу знаний (по имени БД);
  - Плагин для запуска команды в системе (с фильтром команд и фильтром аргументов). С опциональным запросом разрешения у пользователя;
